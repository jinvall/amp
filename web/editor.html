Getting Started

      
Load a WAV or FLAC file using the Load File button in the header, or drag-and-drop onto the Stems panel above.


      
Filters Tab

      
Select filters and adjust parameters. Click Apply Filters to process the loaded file. The result is saved to audio_segments/processed/.


      
Transcribe Tab

      
Run speech-to-text on the loaded file. Requires faster-whisper or whisper installed. Model size trades speed for accuracy.


      
Stems Tab

      
Separate the file into instrument stems. Frequency Band is instant but approximate. Demucs is real ML separation (slow on CPU).


      
MIDI Tab

      
Configure MIDI output from pitch/chord detection. Creates a virtual MIDI port that other DAWs can connect to.


      
Profile Tab

      
Switch between processing profiles. Profiles define which APIs, models, and defaults are active. Edit JSON files in profiles/ to customize.
